# PodLens 使用指南

[English](USER-GUIDE.md) · **简体中文**

收听播客，并可用自己的模型密钥生成逐句转写、翻译和总结。

## 当前可用状态

免费 BYOK 应用。不提供 PodLens 托管 AI 订阅；模型用量由配置的服务商收费。

## 平台与安装

提供 macOS、Windows、Linux 桌面预览；移动与伴随端尚未交付。Linux 当前通过 PODLENS_LANG 选择语言。

从[官方 Releases](https://github.com/turlamai/podlens/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 通过发现页搜索或添加播客 RSS，先播放一集，不启动 AI 任务。
2. 打开设置 → 模型，填入 OpenAI 兼容的 API 地址与密钥，先用「检查连接」验证已保存的配置，再消耗额度。
3. 分别选择具备音频转写和文本翻译能力的服务商与模型；二者能力可能不同。
4. 在单集上点「一键听懂」。确认页会列出已完成的阶段和大致文本量，确认后才会计费；运行中的作业可点「取消」，在下一个检查点停止。
5. 用逐句稿工具栏切换「双语 / 译文 / 原文」，并用「跟随」「当前句」控制阅读位置。「专注聆听」会收起资料库与单集列表，不中断播放，也能原位恢复。
6. 先测试短节目并检查用量，再验证逐句稿导出和播放恢复，最后处理大型资料库。

## 数据、备份与恢复

数据默认在 ~/.podlens：config.json、library.json、audio/、transcripts/。退出后再备份。

API key 不会写入 config.json。从旧版本升级后首次启动时，原先的明文密钥会被迁移到系统安全存储（macOS Keychain、Windows DPAPI 或 Linux Secret Service），config.json 只保留一个不透明引用。系统安全存储不可用时，密钥保存在 `secrets/` 下仅本人可读的文件中，设置页会明确提示。因此备份 config.json 不等于备份密钥：换机恢复后请在设置里重新输入，或通过系统安全存储恢复。不要把 `secrets/` 放进共享备份；密钥一旦泄露应尽快轮换。

## 联网、密钥与隐私

RSS、目录搜索和音频下载会访问相应服务。转写会向选择的服务商上传音频；翻译和总结会发送文字。本地 Ollama 可用不表示它同时支持音频转写。

## 已知限制

长音频作业取消已在共享核心实现并在 macOS 暴露；Windows 与 Linux 已有专注聆听和逐句跳播，但尚未提供取消按钮。Windows MSI 更新使用新版安装器，不会静默替换安装目录。0.6 的阅读优先视觉重构以 macOS 为基准；Windows 与 Linux 暂时保留上一版视觉语言，等下一次 UI 切片收敛。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turlamai/podlens/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
